# 『星の終わりに君は生きる』完成稿（作業ディレクトリ）

作者あにあにの長編『星の終わりに君は生きる』を、設定資料集 v2.6 と既存の公開原稿をもとに、第一部から終幕まで書き下ろし・改稿した完成稿（初稿推敲版）です。本棚アプリの『星の終わりに君は生きる』（`src/data/novels/hoshi/text/`）はこの完成稿に差し替え済みです。旧版の本文は `text_v1/` に残し、旧特別編 `hoshi2` は本棚から外しました（ファイルは保存）。

## 読む順番

- 通して読む：[完成稿_全編.md](完成稿_全編.md)
- 章ごとに読む：[00_目次.md](00_目次.md)
- 先に全体を知りたい：[あらすじ.md](あらすじ.md)（結末まで含む）

## 構成

```
00_目次.md                     章立て・各章の要約・文字数
01_第一部/                      第1〜14章（2059〜2069）
02_第二部/                      第15〜29章（喪失の頁）
03_第三部/                      第30〜40章（君が生きる頁）
04_終幕/                        終幕
完成稿_全編.md                  全章を結合した通読用ファイル（build.py で生成）
あらすじ.md
設定補完と整合性チェック.md     作者未決定箇所の補完一覧、旧本文からの変更点、両頁の生死などの確認表
意図的に残した謎.md             続編・外伝向けに答えを出さずに残した点
作業メモ/                       執筆中の設定整理と進捗（引き継ぎ用）
build.py                        章ファイルから 完成稿_全編.md を再生成する
export_to_app.py                章ファイルから本棚アプリ用の src/data/novels/hoshi/text/*.txt を書き出す
```

章ファイルを直したら `python3 build.py` で通読用ファイルを、`python3 export_to_app.py` で本棚アプリの本文（BGM・挿絵の指定つき）を作り直してください。挿絵とBGMの位置は `export_to_app.py` の `CUES`／`START_BGM` で、本文中の一文を目印に指定しています。

## 表記

- 地の文と会話は一般的な小説表記（段落頭は全角空白、会話は「」）。
- ALMAの声と通信機越しの声は『』。
- 場面転換は「◇」。
- 編集用ラベル（頁A／頁B、湊A／湊Bなど）は本文には出していません。
